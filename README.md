# COLLEGE-ERP-MINI-
A simple College ERP system developed using Python Flask and SQLite to manage students, faculty, attendance, and marks. It provides a secure admin login, dashboard, student management, attendance tracking, and result management. This project demonstrates practical skills in Flask, SQLite, HTML, CSS, SQL, routing, sessions, and CRUD operations.

🎓 College ERP Mini System

A simple web-based College ERP (Enterprise Resource Planning) System developed using Python Flask and SQLite.

The project is designed to demonstrate how a college can manage basic academic information such as students, faculty, attendance, and marks through a centralized web application.

🚀 Features

-  Admin Login
-  Dashboard
-  Student Management
-  Faculty Management
-  Attendance Management
-  Marks / Results Management
-  Student Search
-  Delete Student and Faculty Records
-  Logout
-  SQLite Database

🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- SQL

⚙️ How to Run

1. Install Flask

pip install flask

2. Open the project folder

cd college_erp

3. Run the application

python app.py

4. Open in browser

http://127.0.0.1:5000
